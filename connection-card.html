How video is delivered. The edge authenticates the request, then hands the player a 302 to the provider so the stream is fetched from the player's own IP. The edge cannot proxy it: the provider refuses datacenter ranges, so Cloudflare's egress gets 403 on every channel (verified — the same request returns 200 from a residential IP). Provider credentials are never written into any published file; they live only in Worker env and reach only callers that already passed auth.

Upstream trial expires 2026-10-21 10:21:35. The login response reports Expired once the provider lapses, so a stale build is diagnosable instead of silently broken. Rotate the PROVIDER_* secrets; the workflow rebuilds every 6h, or fire one now with gh workflow run tuliprox-edge.yml.

Client URLs never change across provider rotations — only the PROVIDER_URL / PROVIDER_USER / PROVIDER_PASS GitHub secrets do. Those secrets are the single source of truth: the workflow also pushes them into the Pages environment.

Single connection: the trial allows max_connections=1, so one viewer at a time.
